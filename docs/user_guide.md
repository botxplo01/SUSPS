# SUSPS User Guide

- Start the backend (`uvicorn src.backend.api:app --reload`)
- From `src/frontend`, run the React dev server (`npm install` then `npm run dev`)
- Navigate to the dashboard in the React app (default http://127.0.0.1:5173)
- Select modules (Growth, Energy, Traffic) from the sidebar
- Adjust parameters and time horizons; results update interactively

This guide will expand with screenshots and examples as features land.
